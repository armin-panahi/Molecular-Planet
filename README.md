# سیاره‌ی مولکولی

سیاره‌ای سه‌بعدی و معلق در فضا، ساخته‌شده از هزاران مولکول (آب، دی‌اکسید کربن، اکسیژن، نیتروژن، متان، آمونیاک، گلوکز، هیدروژن) که تماماً با **ژست‌های دست جلوی وب‌کم** کاوش می‌شود — بدون کیبورد، بدون موس، بدون کنترلر.

## ژست‌ها

| ژست | عملکرد |
|---|---|
| 🤏 پینچ شست و اشاره (یک دست) | زوم به سیاره / دور شدن از آن |
| 🖐️ کف دست باز، در حال حرکت | چرخوندن سیاره دور خودش |
| ✊ مشت بسته، در حال حرکت | جابجایی سیاره روی صفحه |
| ☝️ فقط انگشت اشاره باز | نشونه‌گیری روی یک مولکول؛ کمی مکث → باز شدن اطلاعاتش |
| 🖐️🖐️ هر دو دست، کف باز، دور/نزدیک شدن | پخش شدن مولکول‌ها (انفجار) / جمع شدن دوباره به شکل سیاره |

راهنمای کامل همین جدول، به‌صورت زنده و با آیکون، از دکمه‌ی «؟» بالای صفحه هم در دسترسه.

## تکنولوژی

- **Three.js** (`InstancedMesh`) برای رندر ۶۰۰۰ مولکول در یک draw call
- **MediaPipe Tasks Vision — HandLandmarker** برای تشخیص لحظه‌ای ژست دست، مستقیم توی مرورگر (بدون نیاز به سرور تشخیص)
- بدون فریم‌ورک و بدون مرحله‌ی build؛ فقط HTML/CSS/JS با ES Modules، بارگذاری‌شده از CDN (jsDelivr) از طریق import map

## اجرا

این پروژه به دوربین (`getUserMedia`) و ES Modules نیاز داره، که مرورگرها روی `file://‌` مسدودشون می‌کنن. باید از یه سرور محلی سرو بشه:

```bash
python3 -m http.server 8000
# یا
npx serve .
```

بعد `http://localhost:8000` رو باز کن، روی «شروع کاوش» بزن، اجازه‌ی دسترسی به وب‌کم رو بده، و دستت رو جلوی دوربین بگیر. برای بهترین نتیجه از مرورگرهای مبتنی بر Chromium (Chrome، Edge) روی یه محیط با نور کافی استفاده کن.

## تست

```bash
npm install
npm test                        # ۱۳ تست واحد روی منطق تشخیص ژست (js/gestureRecognizer.js)
npx playwright install chromium
npx playwright test             # ۳ تست سرتاسری روی مرورگر واقعی (بوت، منو، جریان کامل شروع)
```

تست‌های Playwright دو مرز بیرونی (jsdelivr برای three.js، و مدل MediaPipe) رو با فایل‌های محلی/شبیه‌سازی‌شده جایگزین می‌کنن تا کاملاً آفلاین و بدون دوربین واقعی اجرا بشن؛ برای دیدن تشخیص واقعی دست، طبیعتاً باید توی یه مرورگر واقعی با دوربین واقعی اجرا بشه.

## ساختار پروژه

```
index.html              نشانه‌گذاری صفحه و import map
style.css                طراحی آزمایشگاه فضایی (پنل‌های شیشه‌ای، رنگ‌های تیل/کهربایی)
js/
  main.js                نقطه‌ی ورود؛ اتصال صحنه + ردیابی دست + کنترلر تعامل + UI
  sceneSetup.js           صحنه‌ی Three.js: دوربین، نور، کهکشان پس‌زمینه، پس‌پردازش bloom
  planet.js               سیاره‌ی InstancedMesh (تولید نمونه‌ها، افکت انفجار، pick با raycaster)
  moleculeData.js          داده‌ی ثابت مولکول‌ها (فرمول، نام، رنگ، توضیح)
  handTracking.js          wrapper دوربین + MediaPipe HandLandmarker
  gestureRecognizer.js      توابع خالص هندسی روی لندمارک‌ها (زاویه‌ی خمش انگشت، پینچ، طبقه‌بندی حالت)
  interactionController.js  ماشین‌حالت ژست → عملکرد (زوم/چرخش/جابجایی/انتخاب/انفجار)
  ui.js                    بروزرسانی DOM: نشان حالت، پنل اطلاعات مولکول، اورلی اسکلت دست
test/
  gestureRecognizer.test.mjs  تست واحد (Node.js test runner)
  app.spec.mjs                تست سرتاسری (Playwright)
```

## نکات

- روی مرورگرهایی که از `delegate: "GPU"` پشتیبانی نکنن، `handTracking.js` خودش به‌طور خودکار به `delegate: "CPU"` سوییچ می‌کنه (کندتر ولی همه‌جا کار می‌کنه).
- انیمیشن‌های محیطی (چرخش خودکار سیاره در حالت بی‌کاری) از تنظیم `prefers-reduced-motion` سیستم پیروی می‌کنن.
- ثابت‌های حساسیت هر ژست (سرعت زوم/چرخش/جابجایی) بالای `interactionController.js` جمع شدن؛ اگه یه ژست به نظرت خیلی تند یا خیلی کند اومد، اول همون‌جا رو تنظیم کن.
